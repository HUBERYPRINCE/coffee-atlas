# 焙境图鉴 · Roast & Terroir Atlas（世界咖啡豆科普 3D 全息闪卡）

> 以 B 站全息闪卡项目（`BV183YT6REBS` / `RuiC-card-skill`）的 3D 光学与多层视差原理为灵感底座，面向精品咖啡爱好者与科普学习打造的 **暗房手冲吧台典藏版 3D 全息闪卡图鉴**。

---

## 快速开箱（三种使用方式）

### 方式一：GitHub Pages 在线访问（推荐，即开即玩）
- **在线主站（轻量分层加载，约 1.2 MB 首屏 + WebP 按需缓存）**：<https://huberyprince.github.io/coffee-atlas/>
- **在线单文件离线镜像（可直接右键另存为本地离线收藏）**：<https://huberyprince.github.io/coffee-atlas/standalone.html>

### 方式二：单文件离线典藏版（零依赖双击即开）
直接用任意现代浏览器（Chrome / Safari / Edge / Firefox）双击打开：

- **`dist/coffee-atlas-3d-standalone.html`**

> 已将 Three.js 渲染核心、全部 36 张科普与单品豆数据、全部 16 套 48 层高定艺术 WebP 图层与全部样式内联打包为单个 HTML 文件（约 `6.6 MB`），**零外链网络请求**，可直接归档进 Obsidian 或分享给咖啡好友离线赏玩。

### 方式三：模块化源码开发 / 本地服务器运行
```bash
# 安装依赖（仅 three + esbuild）
npm install

# 启动零依赖本地开发服务器（默认端口 4173）
node scripts/dev-server.mjs --port 4173
# 浏览器访问 http://127.0.0.1:4173/

# 一键重打单文件离线 HTML（dist/coffee-atlas-3d-standalone.html）
npm run build

# 一键构建静态站点目录（_site/，供 GitHub Pages 自动部署）
npm run build:pages
```

## 核心功能一览

1. **暗房手冲吧台 & 白相美术馆双主题 3D 全息展台（Three.js r187 + 自定义 GLSL）**
   - 零 Blender 依赖程序化圆角倒角厚卡几何体 + 正交局部视角 `uView` 真实多层视差（背景凹陷 / 主体前凸 / 风味粒子悬浮 / 同源配准线稿扫光闪金 / 零视差锁边排版）。
   - **双主题一键切换（快捷键 `T`）**：默认「暗房手冲吧台」深胡桃木沉浸基调 + **随卡动态氛围追光**（如翡翠绿标泛幽绿暗光、朗姆酒桶泛暗酒红光、白山氮气洗泛冰蓝光），随时一键切换致敬 `BV183YT6REBS` 的 **「白相美术馆」暖白宣纸浅色模式**，全站 6 大视图与海报导出同步适配。
   - **沉浸全息交互手感**：支持 **鼠标悬停轻度随动视差（±10°）**、按住拖拽大角度把玩（±38°）、桌面端极简圆环光标、左右悬浮翻卡箭头与单层极简底栏 HUD；GLSL 内置对角微拉丝衍射栅格，鲜明呈现 **烫金（Gold）/ 珠光（Pearl）/ 银箔（Silver）/ 原画棉纸（Original）** 四种光学质感，并支持光泽度调节、4 项景深微调、物理浮雕模式与无 WebGL 自动 CSS 3D 降级。
   - **1400×1800 典藏海报预览与导出**：按 `S` 或点击「保存海报」，自动匹配当前暗房/白相双主题，在画框弹窗中支持正/背面切换重绘并一键下载高清 PNG。
2. **双层卡片阅读与内置三段式手冲计时器**
   - **层 1 · 3D 翻面棉纸卡背（1440×2160 高 DPI）**：单品豆呈现 6 维感官雷达图、Agtron 烘焙色阶游标、实测物理指标（含水率/密度/水活度）、推荐饮用场景与手冲核心参数；百科卡呈现结构化对照表、核心要点与反常识辟谣。
   - **层 2 · 右侧 DOM 精读抽屉（快捷键 `I`）**：3D 卡片平滑左移仍可随时旋转，无删减阅读完整产地故事、种植采摘、处理法详解，支持 **一键复制冲煮配方**、关联卡片互链直达，以及内置 **三段式手冲交互计时器**（分段进度条、实时目标注水克重高亮、WebAudio 柔和木质提示音）。
3. **世界咖啡豆典藏全套图鉴（36 张）与交互式风土地图**
   - **11 款珍藏单品豆（全员博物铜版画 AI 高定分层艺术）**：完整收录巴拿马翡翠庄园绿标瑰夏（`10.8% / 880g/L`）、哥伦比亚玛卡瑞纳朗姆酒桶发酵、埃塞戈里森林瑰夏日晒、卡法瑰夏水洗 & 传统日晒、格拉纳共发酵瑰夏、哥伦比亚白山庄园冷泉水氮气水洗，以及肯尼亚涅里 AA、巴西喜拉多黄波旁、印尼苏门答腊黄金曼特宁、中国云南保山潞江坝老铁皮卡 4 款跨洲基准豆。
   - **5 张核心豆种基因卡（全员博物标本 AI 精绘）**：阿拉比卡（S 缝四倍体）、罗布斯塔 & Fine Robusta 正名（直缝二倍体）、利比里卡（不对称水滴巨豆）、埃克塞尔萨、稀有母本尤金尼奥伊德斯。
   - **20 张深度科普百科卡**：8 大精品细分品种、6 大世界风土产区（含中国云南专题与瑰夏百年迁徙史）、6 大处理法/烘焙度 Agtron/SCA & CVA/物理分级/金杯萃取科学卡。
   - **世界咖啡带交互式风土微图（快捷键 `M`）**：古铜版画风内联 SVG 地图，呈现南北回归线 `23.5°N–23.5°S` 咖啡带、瑰夏百年迁徙弧线与 7 大产区脉冲坐标光点，点击联动筛选画廊或直跳 3D 闪卡。
4. **双豆对比实验室（Compare Lab，快捷键 `C`）**
   - 内置 5 组黄金品鉴对照（首推 `AF-05` 卡法水洗 vs `AF-06` 卡法日晒、瑰夏百年演化、朗姆酒桶 vs 氮气冷洗等），支持任意双豆同轴叠加 6 维感官雷达、差值洞察、同轴双色 Agtron 烘焙游标与 9 维冲煮工艺对照表。
5. **品鉴官闪卡盲测模式（Flashcard Quiz，快捷键 `Q`）**
   - 24 道专业咖啡品鉴题库、5 大专场、实体 3D CSS 翻牌棉纸解析卡背，掌握度自动持久化至浏览器 `localStorage` 并与画廊徽标联动。
6. **我的豆单工坊（My Bean Studio，快捷键 `N`）**
   - 随时录入你新买的任何咖啡豆：**支持直接粘贴中文豆卡文案一键智能解析 17+ 字段**，微调 6 维雷达滑块、可选上传本地照片（自动压缩并裁剪为铜金博物馆标本窗 + 自动 Sobel 配准线稿），即时生成全新 3D 全息闪卡并支持 JSON 导入/导出备份。

## 键盘快捷键速查

| 快捷键 | 功能说明 |
| :---: | :--- |
| `F` / 双击卡片 | 3D 卡片正面 / 背面 180° 翻转 |
| `←` / `→` | 切换上一张 / 下一张卡片 |
| `Space` | 启停暗房自动微摆赏光（盲测背面时进入下一题） |
| `R` | 复位 3D 展台视角与缩放 |
| `I` | 展开 / 收起右侧精读科普档案与手冲计时器 |
| `S` | 打开 `1400×1800` 典藏海报预览与下载弹窗 |
| `G` | 切换 3D 展台 / 全套图鉴 |
| `M` | 在图鉴中展开 / 收起世界咖啡带风土地图 |
| `C` | 进入 / 退出双豆对比实验室 |
| `Q` | 进入 / 退出品鉴官闪卡盲测（`1`–`4` 快捷答题） |
| `N` | 打开「我的豆单工坊」录入新咖啡豆 |
| `T` | 一键切换「暗房手冲吧台」深色 / 「白相美术馆」浅色展台 |
| `?` | 打开快捷键与使用指南速查弹层 |
| `Esc` | 依次关闭弹窗 / 抽屉或返回展台 |

## 工程目录结构

```text
Coffee-Atlas-3D/
├── index.html                        # 模块化开发入口
├── package.json                      # 极简依赖（three + esbuild）
├── assets/hero-beans/                # 16 套（11 单品豆 + 5 核心豆种）× 3 层 WebP（bg / subject / lineart）
├── data/
│   ├── flavor-palette.js             # SCA/WCR 11 大风味族色板与 6 维雷达轴定义
│   ├── beans-catalog.js              # 11 款珍藏单品豆完整档案
│   ├── knowledge-deck.js             # 25 张咖啡植物学、产区、工艺与 SCA/CVA 百科卡
│   └── deck-index.js                 # 36 张卡聚合索引与筛选统计
├── src/
│   ├── main.js                       # 全局路由、快捷键、活跃牌组状态联动
│   ├── styles/atelier-dark.css       # 暗房手冲吧台深胡桃木与暖铜金视觉系统
│   ├── engine/                       # Three.js 程序化厚卡、GLSL 全息着色器、LRU 显存池、CSS 3D 降级
│   ├── art/                          # 5 层植物志正面合成器、1440×2160 高 DPI 棉纸卡背、混合资产解析器
│   └── ui/                           # 展台 HUD、精读抽屉与计时器、画廊、风土地图、对比实验室、盲测、豆单工坊
├── .github/workflows/deploy-pages.yml # GitHub Actions 自动构建并发布 GitHub Pages
├── scripts/
│   ├── prepare_hero_layers.py        # Python/Pillow：去白底、内部孔洞精清与同源 Sobel 线稿提取
│   ├── dev-server.mjs                # 零依赖 Node 本地静态开发服务器
│   ├── build-standalone.mjs          # esbuild 一键单文件离线 HTML 打包器
│   └── build-pages.mjs               # GitHub Pages 轻量静态构建器（输出 _site/）
└── dist/
    └── coffee-atlas-3d-standalone.html  # 开箱即用的单文件离线典藏版
```
